Cómo actualizar y publicar los recuerdos

  1. Edita los campos de la cajita que quieras cambiar: título, objeto, descripción, foto o dulce.
  2. Pulsa Guardar borrador para no perder los cambios en este navegador.
  3. Pulsa Copiar para datos.js. Se copia todo el contenido listo para pegar.
  4. Abre el archivo datos.js en tu editor, selecciona todo (Ctrl+A) y pega lo copiado (Ctrl+V). Guarda.
  5. Publica en GitHub con un commit y push (ver abajo).
  6. GitHub Pages se actualiza solo en aproximadamente 1 minuto.

Opción con IA (más fácil): dile a OpenCode algo como “Actualiza datos.js con estos recuerdos y haz commit y push”, y se encarga de todo.

Opción manual, en PowerShell dentro de la carpeta del proyecto:

cd "C:\Users\carlo\OneDrive\Documentos\Calendario de Adviento" git add . git commit -m "Actualizo recuerdos" git push

Para revisar todas las cajitas antes de diciembre, abre index.html?preview.
